# Viagem Disney

Planejador de viagem para Miami e Orlando: roteiro dia a dia, checklist,
119 atrações com régua de altura, lista de compras, orçamento e reservas.

Arquivo único, sem dependências. Funciona offline depois de instalado
(Compartilhar → Adicionar à Tela de Início) e sincroniza entre aparelhos
por uma API própria, com merge por registro.

Os dados ficam no seu aparelho. Nada é enviado a lugar nenhum sem você
configurar um servidor.
